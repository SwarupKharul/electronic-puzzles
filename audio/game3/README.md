# 🎵 Audio Assets for Game 3 (4-RFID Coins Puzzle)

This directory houses sound effects triggered when players interact with the **Coins Puzzle Prop**:

- `start.mp3`   ➔ Played when Game Master clicks Start (`STARTED` event)
- `failed.ogg`  ➔ Played when 4 coins are placed in the wrong positions / slots (`FAILED` event)
- `success.ogg` ➔ Played when all 4 coins match their designated slots (`COMPLETED` event)

Supported formats: `.mp3`, `.ogg`, `.wav`, `.m4a`
Files are served automatically by the Escape Room Master control server.
